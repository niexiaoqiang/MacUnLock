# MacUnLock

两台 Mac 联动锁屏和解锁。**解锁其中一台，另一台自动解锁；锁定其中一台，另一台也跟着锁定。** 适合 MacBook 和 Mac mini 通过“通用控制”共用一套键盘鼠标的场景，解决“Mac mini 锁屏后通用控制无法唤醒”的问题。

两台 Mac 安装同一个菜单栏 App，默认双向联动，每个方向都可以单独关闭。

## 打包

在有 Xcode 的那台 Mac 上运行：

```bash
./scripts/build-app.sh
```

输出 `dist/MacUnLock.app` 和 `dist/MacUnLock.zip`，同时支持 Intel 和 Apple 芯片。

**建议先做一次固定签名**，否则每次重新打包后，都要在“辅助功能”里重新授权。下面两种方式任选一种：

- 在 Xcode → 设置 → 账户 中登录 Apple ID（免费账号即可），脚本会自动使用 “Apple Development” 证书
- 或者运行一次 `./scripts/create-signing-cert.sh`，创建本地自签名证书。证书放在独立的 `~/.macunlock-signing/` 里，不改动登录钥匙串，也不修改系统的信任设置。**请备份这个文件夹**，换电脑后继续用同一个证书，就不用重新授权

脚本优先使用自签名证书。选定签名方式后不要再换，换了就要重新授权。

## 安装（两台都要做）

1. 把 `MacUnLock.zip` 拷到另一台 Mac，比如通过隔空投送。解压后，把 `MacUnLock.app` 拖进“应用程序”文件夹
2. 打开 App，菜单栏会出现一个锁形图标，点「设置…」
3. **配对**
   - 在 A 机上，把对方的主机名填进「另一台 Mac」，然后按回车。对方的主机名可以在对方设置页的「本机主机名」里看到
   - 在 A 机上点共享密钥的「**复制**」，通过备忘录、信息等方式发到 B 机，在 B 机上点「**粘贴**」
   - B 机也填好 A 机的主机名
   - 点「测试」，显示绿色的“在线”就说明配对成功
4. **让另一台能解锁本机**：在需要被自动解锁的机器上完成以下设置
   - 「辅助功能权限」→ 点「去授权」，在系统设置里打开 MacUnLock
   - 「登录密码」→ 输入本机登录密码并保存。如果钥匙串弹窗询问，选「始终允许」
5. 打开「登录时自动启动」

## Mac mini 的电源设置

接收解锁的那台 Mac **不能进入系统睡眠**，否则收不到指令。锁屏和关闭显示器都没问题。

- **系统设置 → 能耗**：打开「显示器关闭时，防止自动进入睡眠」
- **系统设置 → 锁定屏幕**：「需要输入密码」设为「立即」，关闭显示器的时间按习惯设置

## 日常使用

| 操作 | 效果 |
|---|---|
| 用触控 ID 解锁 MacBook | Mac mini 被点亮并自动解锁，约 1 秒 |
| 按 `Control + Command + Q` 锁定任意一台 | 另一台也会锁定 |
| 菜单栏 →「立即锁定两台 Mac」 | 两台同时锁定 |
| 菜单栏 →「暂停联动」 | 临时关闭，比如别人借用 MacBook 时 |

## 命令行工具

App 里自带一个命令行工具，和 App 共用同一份配置：

```bash
/Applications/MacUnLock.app/Contents/MacOS/dualunlock status
```

可用的子命令有 `status`、`send ping|unlock|lock`、`bench`、`run --dry-run` 等，用于排查问题和测速。

## 工作原理

```
本机                                           另一台
锁屏/解锁事件 ──TCP 47800，HMAC-SHA256 签名──▶ 校验签名、时间戳和 nonce
(com.apple.screenIsLocked/Unlocked)            ├─ lock：立即锁屏
                                                └─ unlock：点亮屏幕 → 确认处于锁屏 → 输入钥匙串里的密码
```

- **防循环**：执行对方的指令后，本机随之产生的锁屏或解锁事件，在 5 秒内不会再转发回去
- **防误输入**：只有在确认处于锁屏状态时才输入密码。等待期间如果已经被手动解锁，就放弃输入
- **重试**：刚解锁时 Wi-Fi 可能还没恢复，发送失败会重试 4 次，每次间隔 1 秒

## 安全说明

- 登录密码只保存在**本机的钥匙串**中，从不经过网络。网络上只传输带签名的指令
- 共享密钥保存在 `~/Library/Application Support/MacUnLock/config.json`，文件权限为 600
- 请求带时间戳，有效窗口 ±15 秒，并有 nonce 防止重放
- 实际效果是：**能解锁其中一台的人，也能解锁另一台**。可以在设置里关掉「允许另一台解锁本机」，把联动变成单向

## 已知限制

- 开启 FileVault 时，重启后的第一次登录仍需手动输入密码
- 两台 Mac 需要在同一个局域网内，并且时钟误差小于 15 秒（系统默认会自动对时）
- 修改登录密码后，需要在设置里重新保存

## 性能（本机回环实测，macOS 27.0.1）

| 指标 | 结果 |
|---|---|
| ping 往返 | 中位数 1.2 ms，P95 4.2 ms |
| 对方处理 ping | 0.1 ms |
| 解锁总耗时 | 约等于「唤醒后等待」设置值（默认 600 ms）加网络延迟 |
| 常驻资源 | App 约 36 MB 内存，空闲时 CPU 为 0% |

```
Sources/dualunlock/      命令行工具
scripts/                 打包、签名脚本
prototype/               最早的原型和实验包（已验证可行，留作参考）
```
